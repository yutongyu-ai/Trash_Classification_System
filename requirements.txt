# Intentionally diverges from backend/requirements.txt: Streamlit Cloud's
# package index doesn't have torch==2.5.1 (the version actually verified via

# newest available pair instead (torchvision 0.28.0 requires torch==2.13.0
# exactly). Only inference-time deps are listed — no fastapi/uvicorn/
# scikit-learn, since streamlit_app.py doesn't use the FastAPI service.
